# Smart Organizer v0.3.0 — управление ПК и организация ярлыков

Windows 10/11, локальная работа, без платных API. Существующие данные `data/` и `logs/` при обновлении сохраняются.

## Реализовано

- Новый встроенный раздел **«Оптимизация ПК»**.
- Опциональный игровой режим: распознаёт запущенные пользователем EXE из списка и снижает приоритет **только явно разрешённых** фоновых EXE (NORMAL → BELOW_NORMAL). При обычном выходе из игры или приложения выполняется обратное восстановление; системные процессы не затрагиваются. Это не гарантирует прирост FPS.
- Чтение сведений об установленных программах Windows, издателе, версии и дате (реестр Win32), просмотр автозагрузки и работающих процессов.
- Проверенное **интерактивное удаление MSI**: выбор программы из перечня зарегистрированных Windows Installer пакетов (GUID + WindowsInstaller=1), повторная сверка реестра, двойное подтверждение и запуск штатного msiexec /x без тихих действий. Невозможно гарантировать автоматический Undo деинсталляции. Даты устанавливаются не у всех приложений; совпадение дат не свидетельствует о рекламе/вирусах.
- История недавних установок позволяет заметить программы, появившиеся в один день.
- Запуск быстрой проверки Microsoft Defender и просмотр последней защиты/обнаружений из Windows Defender **только для чтения**. Удаление и управление карантином остаётся в стандартной «Безопасность Windows».
- Ручная группировка ярлыков `.lnk`/`.url`/`.website` по пользовательским правилам «Название=Категория». Только верхний уровень рабочего стола, предпросмотр, явное подтверждение, SQLite-журнал операций и Undo. Не переустанавливает и не переносит исполняемые файлы и игровые библиотеки.
- Сохранены ранее существовавшие безопасная сортировка Downloads, проекты, файлы, дубликаты/версии, точная проверка SHA-256, карантин и Undo.
- В предыдущем исправлении закрытия: × / Alt+F4 / Ctrl+Q действительно завершают работу, постоянная кнопка «Полностью выйти».
- Единый журнал работников и правила `AGENTS.md` для последующих параллельных изменений.

## Что НЕ следует считать готовым

- Автоматическое удаление adware/PUA своим движком, массовая деинсталляция (кроме ручного одиночного MSI) Win32/MSIX и глубинная очистка остатков реестра — **не реализованы**. Чтобы избежать разрушения Windows, используйте Defender и штатную панель удаления приложений.
- Игровой режим пока **не** обнаруживает абсолютно все игры автоматически и **не** доказывает прирост FPS или 1% low. Укажите имя EXE игры и отдельные фоновые EXE в настройках.
- Полноценный поверхностный Fences-подобный виджет/сегментация экрана не реализован; есть безопасное перемещение ярлыков по группам.
- Автоматическое восстановление приоритетов после аварийного прекращения процесса (kill/crash) не гарантируется. Восстановление выполняется при обычном выходе, выключении режима или закрытии игры.
- Само приложение не измеряет FPS; пользователь должен сравнить фактическое поведение игр.
- Реальная работа на компьютере пользователя ещё не подтверждена, даже если Windows CI и проверка установленного пакета прошли.

## Установка

1. Скачайте `SmartOrganizer-Windows-Installer.zip` из этого релиза.
2. Проверьте SHA-256 по `SHA256SUMS.txt` при необходимости.
3. Распакуйте архив в отдельную папку и запустите `INSTALL.cmd`. Не запускайте файлы непосредственно из ZIP.
4. После установки откройте Smart Organizer — «Оптимизация ПК». Перед игровыми правилами проверьте нужные EXE через список процессов.
5. При обновлении через программу убедитесь, что существующие пользовательские `data/` и `logs/` сохранены.
