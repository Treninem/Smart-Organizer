## !!! ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ ПОЛЬЗОВАТЕЛЯ !!!

**SO-REQ-2026-10-10.** Единое приложение «Smart Organizer» должно объединить **полезные**, а не маркетинговые функции следующих классов ПО:

1. **Игровой бустер** (Razer Cortex / Process Lasso): автоматическое обнаружение выбранных игр, тонкая настройка влияния фоновых приложений, реальные метрики до/после, белые/чёрные списки, безопасный rollback. Не закрывать важные процессы/несохранённые документы и не выключать защиту.
2. **Поиск рекламных/нежелательных установок** (Malwarebytes AdwCleaner): репутационная оценка, проверка PUA/adware, изменения браузеров/автозапуска, рекомендации с указанием доказательств, карантин/восстановление средствами доверенного движка; без ложных обвинений по названию.
3. **Деинсталляция и остатки** (Bulk Crap Uninstaller / Revo): полный каталог Win32/MSIX/Store/portable, фильтры, пакетный список, штатные деинсталляторы с подтверждением, анализ сиротских следов с защитой общих библиотек, отчёт/откат где возможен; никаких тихих удалений.
4. **Порядок файлов/папок** (Easy File Organizer / DropIt): существующий безопасный планировщик, категории, авторские правила, расписание/отслеживание, сортировка загрузок, документов, архивов и медиа, предпросмотр и Undo, поиск дубликатов/версий.
5. **Порядок приложений и рабочего стола** (Stardock Fences): визуальные группы ярлыков «Игры», «Программы», «Работа», «Документы» и правила автогруппировки, без перемещения настоящих установленных каталогов Program Files, Steam и игровых библиотек.
6. **Общая диагностика Windows**: обзор процессов/нагрузки, автозагрузки, дисков и источников лагов, отчёты и точечные рекомендации без агрессивных «чистильщиков».

Пользователь хочет единый интерфейс, приоритет практической производительности игр и реальной защиты от рекламного мусора. Без установки требующих лицензии сторонних продуктов или копирования их кода. Нельзя утверждать, что обычная сортировка файлов сама по себе повышает FPS.

## Решения архитектуры

- **Модульный локальный Windows-продукт**, расширяющий существующие core/ и интерфейс, без облака и платных API.
- Модуль обнаружения угроз не содержит собственного недостоверного антивирусного «движка»; на первом этапе подключается штатный Microsoft Defender и экран сведений. Полная интеграция PUA-remediation требует отдельного тестируемого контракта.
- Игровой режим opt-in. Первая итерация изменяет только класс приоритета выбранных пользователем приложений: NORMAL → BELOW_NORMAL; затем возвращает исходный. Не трогать CPU affinity или питание без тестов на железе.
- Автосортировка наследует существующие проверенные условия (границы проекта, существующая цель, не перезаписывать, пакетный preflight, Undo).
- Разработческие записи отслеживаются в этом документе; пользовательские журналы остаются локальными.
